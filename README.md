## 🚀 Como rodar o projeto?

<details>
  <summary>👩‍💻 Clonar repositório</summary>
  <br>

  ```bash
  git clone https://github.com/kayqueds/Codando-Sonhos-Sistema-de-API.git
 ```
 </details>

 <details>
 <summary>📂 Acessar pasta</summary>
<br>

  ```bash
  cd Codando-Sonhos-Sistema-de-API
 ```
 </details>
 <details>
 <summary>🌳 Criar ambiente virtual</summary>
<br>

  ```bash
  python -m venv venv
 ```
 </details>

<details>
 <summary>🔧Ativar Ambiente</summary>
<br>

  ```bash
  venv\Scripts\activate
 ```
 </details>

<details>
 <summary>📚 Instalar bibliotecas (libs)</summary>
<br>

  ```bash
    pip install -r requirements.txt
```
 </details>


<details>
 <summary>⚙ Configurando .env</summary>
<br>

* Abra o arquivo .env
* E coloca as suas credenciais do Banco de Dados
 </details>

<details>
  <summary>🗄️ Banco de dados (MySQL)</summary>

  <br>

  * Baixe o script SQL no link abaixo:

  https://github.com/kayqueds/Codando-Sonhos-Sistema-de-API/raw/main/database/schema.sql

  <br>

  Abra o MySQL Workbench e execute o script.

</details>



<details>
 <summary>▶ Rodar a aplicação</summary>
<br>

  ```bash
    python src/app.py
```
 </details>
