1️⃣ ABRA POWERSHELL

   Digite:
   cd "c:\Users\Henrique\Desktop\PROJETOS FINAIS\Projeto_QA"

3️⃣ EXECUTE O SERVIDOR

   Digite UMA DESSAS OPÇÕES:

   python -m src
