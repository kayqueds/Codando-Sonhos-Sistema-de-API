🌐 ROTAS DISPONÍVEIS
─────────────────────────────────────────────────────────────────

🏠 PÁGINAS WEB (HTML):
  GET  /                    → Home (página inicial)
  GET  /register-page       → Formulário de cadastro
  GET  /login-page          → Formulário de login
  GET  /dashboard           → Dashboard do usuário (requer login)
  GET  /movies-page         → Gerenciar filmes (requer login)

🔌 API REST (JSON):
  POST /auth/register       → Cadastrar novo usuário
  POST /auth/login          → Login e obter JWT
  GET  /users               → Listar todos os usuários
  GET  /users/<id>          → Obter um usuário
  PUT  /users/<id>          → Atualizar usuário
  DELETE /users/<id>        → Deletar usuário
  POST /movies              → Criar novo filme
  GET  /movies              → Listar meus filmes
  PUT  /movies/<id>         → Atualizar filme
  DELETE /movies/<id>       → Deletar filme

🔐 COMO FUNCIONA A AUTENTICAÇÃO
─────────────────────────────────────────────────────────────────

Fluxo Completo:

1. Usuário acessa /register-page
2. Preenche: Nome, Email, Senha
3. Clica "Cadastrar" → POST /auth/register
4. Servidor cria usuário no MySQL
5. Usuário acessa /login-page
6. Preenche: Email, Senha
7. Clica "Login" → POST /auth/login
8. Servidor verifica credenciais
9. Retorna: { "access_token": "JWT...", "user": {...} }
10. JavaScript salva JWT em localStorage
11. Requisições posteriores incluem JWT no header:
    Authorization: Bearer <JWT>
12. Servidor valida JWT
13. Usuário acessa rotas protegidas (dashboard, filmes)

📝 EXEMPLO: TESTAR VIA POSTMAN OU CURL
─────────────────────────────────────────────────────────────────

1. Cadastrar:
curl -X POST http://localhost:5000/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "João Silva",
    "email": "joao@example.com",
    "password": "senha123"
  }'

2. Login:
curl -X POST http://localhost:5000/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "joao@example.com",
    "password": "senha123"
  }'

Resposta:
{
  "access_token": "eyJ0eXAiOiJKV1QiLCJhbGc...",
  "user": {...}
}

3. Usar token para listar usuários:
curl -X GET http://localhost:5000/users \
  -H "Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGc..."

⚠️  POSSÍVEIS ERROS
─────────────────────────────────────────────────────────────────

❌ Erro: "Connection refused"
   Solução: MySQL não está rodando
   → Inicie: Services > MySQL80 > Restart
   → Ou use: MySQL Workbench

❌ Erro: "Database does not exist"
   Solução: Banco não foi criado
   → Execute: python init_db.py

❌ Erro: "Cannot import module"
   Solução: Dependências não instaladas
   → Execute: pip install -r requirements.txt

❌ Erro: "Port 5000 already in use"
   Solução: Outro processo está na porta 5000
   → Parar o servidor anterior: CTRL + C
   → Ou mudar a porta em src/app.py
