⚠️  POSSÍVEIS ERROS E SOLUÇÕES
─────────────────────────────────────────────────────────────────

❌ "Connection refused" ou "MySQL connection error"
   
   □ Verificar se MySQL está rodando:
     - Windows Services → MySQL80 → Status: Executando
     - Ou abrir MySQL Workbench
   
   □ Verificar credenciais em .env:
     DB_USER=root
     DB_PASSWORD=99261632
     DB_HOST=localhost
     DB_PORT=3306
   
   □ Se usou outra senha no MySQL, ajuste em .env


❌ "Database does not exist"

   □ Verifique se o banco "sistema_api" foi criado
   
   □ Execute novamente:
     python init_db.py


❌ "ModuleNotFoundError" ou "ImportError"

   □ Instale as dependências:
     pip install -r requirements.txt
   
   □ Se o pip.exe não funcionar:
     python -m pip install -r requirements.txt


❌ "Address already in use"

   □ Outro processo está na porta 5000
   
   □ Solução 1: Parar o outro servidor (CTRL+C)
   
   □ Solução 2: Usar outra porta no src/app.py:
     if __name__ == '__main__':
         app.run(debug=True, port=5001)


❌ "Port 5000 not found" no navegador

   □ Verifique se o servidor está realmente rodando
   
   □ Procure: "Running on http://127.0.0.1:5000"
   
   □ Se não encontrar, execute:
     python -m src.app


❌ Formulário não funciona / Erro ao cadastrar

   □ Verifique o console do navegador:
     F12 → Console → Procure erros
   
   □ Verifique se o servidor está rodando
   
   □ Teste via Postman (veja GUIA_EXECUCAO.md)
